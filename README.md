## How to recreate the files yourself

1. **Download the original PaySim data from Kaggle:** https://www.kaggle.com/datasets/ealaxi/paysim1 (free account required; zip is 186 MB). Unzip it to get `PS_20174392719_1491204439457_log.csv` (6,362,620 records, SHA-256 `16910f90577b0d981bf8ff289714510bb89bc71bff7d3f220f024e287e4eea6b`).
2. **Split it into the two real halves:** a CSV for the first half and a JSON array for the second half, in the file's original order.
   ```
   python scripts/split_paysim.py --input PS_20174392719_1491204439457_log.csv --json-format array --out-dir data
   python scripts/verify_split.py PS_20174392719_1491204439457_log.csv data/paysim_first_half.csv data/paysim_second_half.json
   ```
   The verification must report 21/21 checks passed.
3. **Generate the two synthetic months:** the same seeds give byte-identical files.
   ```
   python scripts/generate_synthetic.py --real PS_20174392719_1491204439457_log.csv --seed 2026 --out data/paysim_synthetic.csv
   python scripts/generate_synthetic.py --real PS_20174392719_1491204439457_log.csv --calibration data/calibration.json \
       --start-step 744 --steps 743 --seed 2027 --format json-array \
       --exclude-ids-from data/paysim_synthetic.csv --out data/paysim_synthetic_month2.json
   ```
4. **Check the files:** compare their SHA-256 against the table above. On Windows: `certutil -hashfile <file> SHA256`.
5. **Optional comparison with the real data:**
   ```
   python scripts/compare_to_real.py PS_20174392719_1491204439457_log.csv data/paysim_synthetic.csv
   ```
